### Story: Create Dockerfile for kube-kg service

**Status:** Done

**Story**

As a developer,
I want a Dockerfile for the `kube-kg` service,
so that I can build a container image for deployment.

**Context Source**

*   Source Document: `docs/prd/epic-5-containerization-and-deployment.md`
*   Enhancement Type: New feature
*   Existing System Impact: None

**Acceptance Criteria**

1.  A `Dockerfile` is created in the root of the project.
2.  The `Dockerfile` builds a container image for the `kube-kg` service.
3.  The container image is as small as possible.
4.  The container image can be run successfully.

**Dev Technical Guidance**

*   **Existing System Context:** The `kube-kg` service is a Go application. The main package is in `cmd/kube-kg`.
*   **Integration Approach:** This is a new file, so no integration is needed.
*   **Technical Constraints:** The Go version is 1.24.6.

**Tasks / Subtasks**

*   [x] Task 1: Create a multi-stage `Dockerfile`.
    *   [x] Use a build stage to build the Go application.
    *   [x] Use a final stage to create a minimal image with the compiled application.
*   [x] Task 2: Add a `.dockerignore` file.
*   [x] Task 3: Verify the Docker image.
    *   [x] Build the Docker image.
    *   [x] Run the Docker image.
    *   [x] Verify that the service starts successfully.

**Risk Assessment**

*   **Implementation Risks:**
    *   **Primary Risk:** The Docker image may not be optimized for size.
    *   **Mitigation:** Use a multi-stage build.
    *   **Verification:** Check the size of the final image.
*   **Rollback Plan:** Delete the `Dockerfile`.
